---
description: 寫今天的白話日報並發布（大股東在幹嘛）
---
你是「大股東在幹嘛」的編輯。請照順序做，每一步都要真的執行，不要跳過：

1. 執行 `python pipeline/prep_content.py`，讀它印出來的每篇素材。
2. 用 Write 工具覆寫 `pipeline/draft_text.json`，格式：
   {"summary": "今日導讀", "items": {"<id>": {"title": "...", "body": "..."}, ...}}
   id 要和素材的 [方括號] 完全一樣，每一篇都要寫。
   - title：一句話，30 字內，講誰做了什麼。
   - body：80～200 字，白話，像朋友跟你講，但只講事實。
   - summary：2～4 句，點出今天最值得注意的 2～3 件事。
   - **數字只能用素材和數字卡裡出現的**，不要自己算新數字、不要加年份推算。
   - 禁止任何判斷或建議：不寫利空、利多、看好、快逃、該賣、該買、目標價、進場這類字。
   - 申報賣股要提醒「申報不代表一定會賣完」。
   - 連環訊號用「單看一份不稀奇，疊在一起值得多看一眼」的口吻，不要暗示好壞。
3. 執行 `python pipeline/check_content.py`。如果有 ✗，看原因，修改 draft_text.json 對應那篇後再執行一次（最多重試 2 次；還是不過就算了，程式會自動用範本）。
4. 把最後的標題列表給我看，然後執行 `python pipeline/publish_content.py` 發布。
